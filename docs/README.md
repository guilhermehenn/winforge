## Como estes documentos são escritos

- Em português do Brasil, com frases curtas e as palavras do dia a dia, como as telas do WinForge.
- Os números foram contados no código de quando cada documento foi escrito. Os de uma revisão ficam como estavam, porque contam aquele momento; a documentação técnica e o mapa de funcionalidades acompanham o código.
